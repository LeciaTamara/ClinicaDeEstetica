**Objetivo do projeto:**

O sistema tem como finalidade oferecer uma plataforma eficiente para o gerenciamento completo de uma clínica de estética.   
Seu propósito central é permitir que o administrador: Cadastre e controle os serviços, planos e funcionários da clínica;  
Mantenha um ambiente organizado e acessível para os usuários.Além disso, o sistema disponibiliza funcionalidades que garantem   
autonomia e praticidade aos outros perfis, onde os funcionários podem consultar e editar suas informações diretamente na plataforma;  
E os clientes têm a possibilidade de criar uma conta, acessar seus dados e realizar atualizações sempre que necessário.

**Instruções para executar o sistema localmente:** 

1° \- Rode o servidor do django utilizando na pasta do projeto utilizando: python3 manage.py runserver  
2° \- Acesse a url: clinicaEstetica/index/
